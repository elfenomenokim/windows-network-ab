# Code of conduct

## Pledge

We want people to be able to use, discuss and improve this project without
harassment. Everyone who participates is responsible for following this
code of conduct.

## Standards

- Give specific, respectful feedback.
- Consider other participants' experience and working conditions.
- Accept corrections and focus disagreements on the work.
- Protect personal information shared in a discussion.

Harassment, threats, insults, unwanted sexual attention and sharing other
people's private information without consent are unacceptable.

## Scope

This code applies to repository issues, pull requests and other project
spaces. It also applies when someone represents the project in public.

## Enforcement

Use a [GitHub private report](https://docs.github.com/en/communities/moderating-comments-and-conversations/reporting-abuse-or-spam)
for a conduct issue. Include links and enough context for a maintainer
to understand what happened. Maintainers may remove harmful content,
limit participation, or block repeat offenders. Handle reports with care
for the privacy of the people involved.

## Attribution
